# کد وب‌سایت فروشگاه آنلاین لوجان

Next.js (App Router) + React + TypeScript (strict) + Tailwind CSS v4 — راست‌به‌چپ، فونت وزیرمتن، رنگ‌های سیستم طراحی ۰٫۱.
قوانین پروژه: `../CLAUDE.md` · نیازمندی‌ها: `../docs/`

## اجرای محلی (یک بار)

نیاز: Node.js نسخه ۲۲ (`node -v`)

```bash
cd web
npm install
npm run dev
```

سپس http://localhost:3000 را باز کنید.

## پایگاه داده (یک بار) — M1.2

1. در **DBngin** روی «+» بزنید، **PostgreSQL** (نسخه ۱۶ یا ۱۷) با پورت `5432` بسازید و **Start** کنید.
2. در پوشه‌ی `web`:

```bash
cp .env.example .env        # نشانی پایگاه داده آماده است
npm install                  # بسته‌های جدید Prisma
npm run db:migrate -- --name init   # ساخت جدول‌ها + بارگذاری داده‌ی نمونه
# دیدن داده‌ها: در TablePlus اتصال PostgreSQL با Host=127.0.0.1، Port=5432، User=postgres، Database=lujan_store
```

اگر پورت ۵۴۳۲ در DBngin عدد دیگری است، همان را در `.env` بگذارید. اگر داده‌ی نمونه بارگذاری نشد: `npm run db:seed`. برای پاک کردن کامل و شروع دوباره: `npm run db:reset`.

## دستورها

| دستور                           | کار                                                         |
| ------------------------------- | ----------------------------------------------------------- |
| `npm run dev`                   | اجرای سایت در حالت توسعه                                    |
| `npm run check`                 | بررسی نوع‌ها، لینت، قالب‌بندی و تست‌های واحد                |
| `npm run build`                 | ساخت نسخه‌ی تولید                                           |
| `npm run db:studio`             | دیدن و ویرایش داده‌ها در مرورگر                             |
| `npm run test:e2e`              | تست سرتاسری (اول یک بار: `npx playwright install chromium`) |
| `docker build -t lujan-store .` | ساخت تصویر Docker برای سرور                                 |

## ساختار

```
src/
  app/          صفحه‌ها و مسیرها (App Router)
  components/   اجزای مشترک رابط (Ruler, ...)
  content/fa.ts همه‌ی متن‌های فارسی رابط
  lib/          ابزارهای مشترک (قالب‌بندی تومان و ارقام، اتصال پایگاه داده db.ts)
  modules/      ماژول‌های کسب‌وکار؛ هر کدام فقط از index.ts خودش import می‌شود
e2e/            تست‌های سرتاسری Playwright
prisma/         شِمای پایگاه داده، داده‌ی نمونه و مایگریشن‌ها
```

## قراردادها

- توکن‌های رنگ و فونت در `src/app/globals.css`، منتقل‌شده از `../design/ds.css`؛ کلاس‌ها: `bg-bg`, `text-ink`, `bg-copper`, `rounded-card`, `ruler`, ...
- قیمت‌ها همیشه با `formatToman()` نمایش داده می‌شوند؛ ورودی عددی کاربر با `toLatinDigits()` ذخیره می‌شود.
- هر کامیت به شناسه‌ی نیازمندی ارجاع می‌دهد، مثل `FR-CART-03: ...`.

## کارهای زمان‌بندی‌شده روی سرور (cron)

| دستور                    | زمان پیشنهادی     | کار                                                                            |
| ------------------------ | ----------------- | ------------------------------------------------------------------------------ |
| `npm run jobs:release`   | هر ۵ دقیقه        | لغو سفارش‌های پرداخت‌نشده‌ی منقضی و آزادسازی رزرو (FR-CHK-07)                  |
| `npm run jobs:low-stock` | هر روز ساعت ۸ صبح | پیامک خلاصه‌ی کالاهای تازه کم‌موجود به مدیر کل و انباردار (FR-INV-04، D-043)   |
| `npm run jobs:backup`    | هر شب ساعت ۳      | پشتیبان پایگاه داده و تصویرها در `backups/`، نگهداری ۳۰ روز (FR-ADM-14، D-051) |

بازگردانی فقط روی سرور: `npm run backup:restore` (فهرست) و `npm run backup:restore -- <نام فایل>` (با تأیید). متغیرهای اختیاری: `BACKUP_DIR`، `BACKUP_KEEP_DAYS`، `PG_BIN_DIR` (پوشه‌ی pg_dump؛ روی مک DBngin خودکار پیدا می‌شود).

روی سیستم توسعه لازم نیست؛ هر دو را می‌توان دستی هم اجرا کرد.
