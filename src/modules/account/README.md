# ماژول account — حساب کاربری و ورود

- نیازمندی‌ها: `FR-ACC-01..04, 06`، `FR-CART-02` (ادغام سبد)، `NFR-SEC-05` (محدودیت نرخ کد)
- ورود: موبایل ← کد ۵ رقمی (۲ دقیقه، ۵ تلاش، هش HMAC) ← نشست ۳۰ روزه با کوکی httpOnly؛ فقط هش توکن در پایگاه داده (D-021).
- پیامک: `sms.ts` (فعلاً حالت توسعه، D-019) — کد در ترمینال سایت چاپ می‌شود.
- رابط: `index.ts` (مرورگر)، `server.ts` (سرور)، `actions.ts` (Server Actionها، قابل import در کامپوننت کلاینت).
