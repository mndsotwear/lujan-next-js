# ماژول catalog — کاتالوگ محصول

- نیازمندی‌ها: `FR-CAT-*` (ردیاب: `docs/08-tracking/01-requirements-tracker.md`)
- رابط عمومی: `index.ts` (منطق خالص، امن برای مرورگر) و `server.ts` (پایگاه داده، فقط سرور).
