# ماژول admin — پنل مدیریت

- نیازمندی‌ها: `FR-ADM-*`، NFR-SEC-04، NFR-SEC-07 (ردیاب: `docs/08-tracking/01-requirements-tracker.md`)
- تصمیم‌ها: D-034 (پنج بخش M1.9)، D-035 (ورود کارکنان)، D-036
- قانون معماری: بقیه‌ی کد فقط از `index.ts` (مرورگر)، `server.ts` (سرور) و `actions.ts` (Server Action) import می‌کند.

## ورود کارکنان (D-035)

1. مدیر کل در «کارکنان» موبایل و نقش را ثبت می‌کند.
2. کارمند در `/admin/activate` با کد پیامکی تأیید می‌کند، رمز قوی می‌گذارد، QR را در اپ کدساز اسکن می‌کند و ۸ کد پشتیبان می‌گیرد.
3. ورود: `/admin/login` ← رمز ← کد ۶ رقمی (یا یک کد پشتیبان). ۵ تلاش ناموفق = ۱۵ دقیقه قفل.
4. گوشی گم شد: مدیر کل «بازنشانی ورود» را می‌زند و کارمند دوباره فعال‌سازی می‌کند.

نشست پنل جدا از نشست مشتری است (`AdminSession`، کوکی `admin_session`، SameSite=Strict، حداکثر ۱۲ ساعت، ۲ ساعت بی‌فعالیتی).
هر صفحه با `requireStaff(permission)` و هر Server Action با `staffWith(permission)` بررسی می‌شود؛ جدول مجوزها در `permissions.ts`.
