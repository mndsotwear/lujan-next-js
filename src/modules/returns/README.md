# ماژول returns — مرجوعی و تعویض

- نیازمندی‌ها: FR-RET-01، FR-RET-02 (نمای مشتری؛ گردش‌کار اپراتور در M1.9)، FR-RET-04
- تصمیم‌ها: D-030 (شرایط)، D-033 (محل تصویر)
- `policy.ts` منطق خالص و تست‌شده؛ `actions.ts` ثبت درخواست؛ `queries.ts` و `storage.ts` فقط سرور.
- تصویرها در `web/storage/returns/` (بیرون از `public`) و فقط از مسیر `/api/returns/image/<نام>` با بررسی مالکیت نمایش داده می‌شوند. پوشه‌ی دیگر با متغیر `UPLOAD_DIR`.
