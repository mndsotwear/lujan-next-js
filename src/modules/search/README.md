# ماژول search — جستجو

- نیازمندی‌ها: `FR-SRCH-01..03, 05` (۰۴ جستجوی معنایی در فاز ۳)
- موتور: Meilisearch اگر `MEILI_URL` تنظیم شده باشد (D-002)، وگرنه موتور داخلی `rank.ts` (یکسان‌سازی فارسی + غلط املایی + مترادف). اگر Meilisearch قطع شود خودکار به موتور داخلی برمی‌گردد.
- همگام‌سازی Meilisearch: `npm run search:sync`
- رابط: `index.ts` (امن برای مرورگر) و `server.ts` (فقط سرور).
